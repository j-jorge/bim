Bim! Privacy Policy

Bim! is a game developed by Julien Jorge, but it does not matter. It is free software with no ad, no tracker, no trick for the end user.

I do not collect personal data but I do collect anonymous, non-identifying data. For example (non-exhaustive):

  • the language in which your device is configured, so I know which translations I should work on,
  • which buttons are clicked, so I know if something is useless in the user interface,
  • which errors happen, so I know if there is an issue I should address.

These data are collected using PostHog and stored in Europe.

Additionally, a normal workflow for this game requires many connections to its server during the session, in order to manage the player's state. The device is recognized by the server using a random identifier generated on the client when the app is launched for the first time. If no user exists for this device, the server will silently create one.

The device ID is not shared with any other service. Also, note that the device ID will change if you wipe de app's data. Your account may not be recoverable.

Finally since this is an online game, I must also necessarily get your device's IP address. This address will appear in the logs of the web services.
